# Space News Skills

This repository contains the current `space-news` and `wechat-space-news-draft` skills extracted from a local OpenClaw setup.

## Included

- `space-news`: Chinese space intelligence brief workflow, search rules, references, and scripts
- `wechat-space-news-draft`: WeChat draft upload skill and related scripts

## Safety

- No API keys, tokens, or local secrets are committed.
- Scripts read credentials from CLI flags or environment variables.
- Generated local artifacts, caches, and transient candidate data are excluded.
