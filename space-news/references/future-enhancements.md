# 后续增强清单

这是 `space-news` 的后续增强方向，当前不是必需，但以后很值得做。

## 1. 更强的采集层

- 接入稳定的搜索 API key，降低人工收集成本
- 增加按来源白名单定向检索
- 增加去重逻辑，避免同一事件被多次计入
- 增加时间解析，而不是统一使用采集当天日期

## 2. 更细的排序逻辑

- 对机构官方发布给予更高权重
- 对论文、会议、开源项目分别设置子排序规则
- 对军事、商业、民用、科研场景做平衡采样，避免输出过度偏向某一类
- 对“真实落地”与“概念宣传”做区分

## 3. 更强的结构化字段

- 自动抽取涉及主体
- 自动提取国家 / 地区
- 自动识别任务类型、项目名、模型名、机构名
- 增加多来源交叉确认字段

## 4. 更好的写作质量

- 引入更稳定的详细中文介绍生成流程
- 区分“摘要式简报”和“深度版简报”两种输出模式
- 增加按主题分组的小结
- 支持输出 Markdown 与 DOCX 两种版本

## 5. 运营化能力

- 接入 cron 做每周自动运行
- 保留历史结果，便于比较趋势
- 生成 diff，标记本周新增的重要事件
- 记录长期高频机构、热门方向和高价值开源项目
