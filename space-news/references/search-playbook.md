# 检索指引

用于生成航天领域情报简报，重点关注 AI 在航天领域的发展。

## 默认检索顺序

先找高权威来源，再补充媒体与开源社区：

1. 官方机构与官方页面
2. 高校、实验室、论文、会议页面
3. GitHub 与项目主页
4. 高质量航天媒体与主流媒体
5. 官方社交账号或二级转载页面（仅作补充）

## 建议来源类型

### 官方与机构
- NASA
- ESA
- JAXA
- ISRO
- CNSA 及相关公开页面
- 商业航天公司官网、新闻稿、博客

### 高校与科研
- 高校新闻页、实验室页面
- arXiv
- 会议官网
- 期刊或技术报告页面

### 开源与项目
- GitHub 仓库
- 官方项目文档站点
- 发布说明、release notes、路线图页面

### 媒体
- SpaceNews
- Space.com
- Reuters
- AP
- 其他可信航天媒体

## 推荐检索维度

围绕下面几类关键词组合检索：

- 航天 AI / AI for space / space AI
- onboard AI / autonomy / mission operations AI
- guidance navigation control AI / autonomous rendezvous / docking
- remote sensing AI / Earth observation foundation model / SAR AI
- digital twin / simulation / verification / test automation for space
- space robotics / servicing / SSA / STM intelligence
- space startup AI / space agency AI program / space AI conference
- GitHub + 遥感 AI / 航天仿真 / 轨道设计 / mission analysis

检索时要主动覆盖下列场景，不要只盯科研或机构新闻：

- 军事与国防航天：太空态势感知、导引控制、侦察监视、军用卫星、空间安全
- 商业航天：初创公司、融资、产品发布、合同合作、商业遥感与卫星服务
- 民用与公共服务：气象、灾害监测、导航、通信、城市与农业遥感应用
- 科研与学术：论文、实验室成果、会议、技术验证、开源工具
- 国际机构与国家项目：NASA、ESA、JAXA、ISRO、CNSA 等机构及国家级计划

## 去重与筛选

- 同一事件优先保留原始来源。
- 二次转载如果没有新增信息，通常不单独入选。
- 与航天关系弱、只有“AI”但没有空间应用场景的内容剔除。
- 只保留在当前时间范围内公开发布、更新、发稿或具有明确时间锚点的内容。

## 写作提醒

- 最终不是搜索结果清单，而是情报简报。
- 要先判断重要性，再写中文介绍。
- 如果候选很多，宁可少而精，也不要把低信号内容硬塞满。
